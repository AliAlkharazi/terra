The scene file is created by Unity on first open.

Menu: Terra → Build World Scene
Output: Assets/Scenes/TerraWorld.unity

Press Play. The Hierarchy shows Camera, Budget Hall, and the seven districts (Dining, Groceries, Transport, Entertainment, Shopping, Subscriptions, Other). The view starts zoomed out so all of them fit. Pitch is 47.5°, yaw is fixed. If this scene file is missing, Play still builds that town.

Checklist: docs/unity-world/SPIKE_AB_PLAYMODE_AC.md

Do not hand-write the scene YAML. See the repo README.
